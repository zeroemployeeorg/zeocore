Voice router: the vendor engines for the open voice examples move into Core as standalone engines in `zeo_core.voice.providers`: OpenAI text-to-speech and the shared HTTP base, Speechmatics realtime speech-to-text, and local faster-whisper speech-to-text with its endpointing base. They import no framework and add no required dependency: HTTP uses httpx, the websockets and faster-whisper packages are imported when used, and a missing one makes the engine "not configured here" so the router skips it like a missing key. Core reads no credential: the API key is a constructor argument. The framework bridge for these engines is not part of Core.
