**Add `packages/react`: a data-only React renderer, a strict browser validator and a card gallery for the `intervention_card` payload.** It renders all ten situations, validates the bytes of a card in the browser with the published schema plus the rules the schema cannot express, and offers typed local intents for replies and results; approvals render no control. The TypeScript types and the browser rules are generated from the Python models by `scripts/generate_react_contract.py`, with a drift test. `make verify-ui` builds and tests the package from its lockfile, and `make verify-full` runs it. The package is not published to a registry.
