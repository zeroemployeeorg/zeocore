Developer tooling only; nothing under `src/` changes, so the wheel is functionally the same as the previous release. `make help` points to the new `make help-all`, which lists every target. `make doctor` checks more of a machine (Python, uv, git, network, `ZEO_WORK_DIR`, and whether the git hooks are installed, as a warning). The pre-push hook refuses a push to `main`. `make release-candidate` builds the wheel and sdist with a checksum file on Linux, and `make release` explains how releases work and exits non-zero; neither tags or uploads. The README points contributors to `make help`, `make doctor` and `make verify`.
